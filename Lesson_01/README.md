# Lesson 01: CSS Introduction & Core Concepts

Welcome to the first part of the CSS learning series. This module covers the foundational concepts of CSS, its core purpose, and why it is indispensable in modern web development.

---

## 1. CSS Introduction

**CSS** stands for **Cascading Style Sheets**. It is a stylesheet language used to describe the presentation of a document written in a HTML or XML. While HTML focuses on the **structure** and **content** of a webpage, CSS focuses entirely on the **design**, **layout**, and **visual aesthetics**.

### How CSS Works: The Selector & Declaration Block
CSS works by associating rules with HTML elements. A CSS rule-set consists of a **selector** and a **declaration block**.

```css
selector {
  property: value;
  text-align: center;
}
```
---
## 2. Why Use CSS?
Before CSS was introduced in 1996 by the W3C (World Wide Web Consortium), HTML tags like <font>, color attributes, and complex tables had to be used to style webpages. This made code messy, hard to maintain, and inefficient.

### Here are the key reasons why we use CSS in modern web development:

#### I. Separation of Content and Presentation
- CSS allows developers to separate the presentation layer (styles, fonts, colors, layouts) from the structural layer (HTML code). This keeps the code clean, highly readable, and semantic.

#### II. Consistency and Efficiency (Save Time)
- Instead of styling every single HTML element individually, you can write a CSS rule once and apply it across multiple elements, sections, or even hundreds of web pages. If you need to change a font color across your entire website, you only need to update a single line in your external CSS file.

#### III. Enhanced User Experience & Layout Control
- CSS provides advanced layout mechanisms like Flexbox and CSS Grid that allow you to create complex, beautiful layouts that are impossible to achieve with pure HTML. It gives you precise control over spacing, typography, positioning, and animations.

#### IV. Responsive Web Design (RWD)
- With the rise of mobile devices, websites must look good on screens of all sizes. CSS introduces Media Queries, enabling web pages to automatically adapt their layouts, font sizes, and visibility based on the user's screen size (Mobile, Tablet, Desktop).

#### V. Faster Page Loading Speeds
- When using external CSS files, browsers cache (store) the stylesheet after the first page load. This means subsequent pages load much faster because the browser doesn't need to re-download the layout and styling information for every new page the user visits.
